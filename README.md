# SnapClass AI - Attendance System

An intelligent, AI-powered classroom attendance management application built with **Streamlit**, **Computer Vision (Dlib)**, and **Voice Biometrics (Resemblyzer)**.

## ✨ Features
- **Face ID Attendance**: Scan and identify students from classroom photos in seconds.
- **Voice Attendance**: Verify presence through biometric voice embeddings.
- **Teacher Dashboard**: Manage courses, generate QR enrollment codes, and track attendance records.
- **Student Portal**: Self-enroll in courses and review attendance history.
- **Lightweight & Fast**: Powered by a local SQLite database and optimized neural network inference.

## 🚀 Quickstart

### 1. Clone the repository
```bash
git clone https://github.com/TechieRahul-svg/intelligent-ai-cls.git
cd intelligent-ai-cls
```

### 2. Set up virtual environment
```bash
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.
